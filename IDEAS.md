# Idea Matrix — Công cụ tự sinh ý tưởng

## Cách dùng
Chọn 1 ô từ mỗi cột → ghép lại → bạn có 1 ý tưởng.

| Đối tượng | Vấn đề | Giải pháp | Platform |
|-----------|--------|-----------|----------|
| Developer | Quản lý API keys | Dashboard kéo thả | Web App |
| Freelancer | Tạo invoice | AI tự động | Chrome Ext |
| Team nhỏ | Deploy tốn thời gian | One-click deploy | Desktop App |
| Sinh viên | Học khó tập trung | Gamification | Mobile App |
| Người già | Quên mật khẩu | Biometric + backup | API |
| Game thủ | Cấu hình máy | Auto-detect + optimize | CLI |
| Blogger | Viết SEO | AI analyze realtime | VSCode Ext |
| Bác sĩ | Quản lý lịch hẹn | Auto-scheduler | Telegram Bot |
| Chủ quán cafe | Menu + gọi món | QR code ordering | PWA |
| Fitness coach | Theo dõi học viên | Progress tracker | SaaS |

## Ví dụ ghép
Developer + API keys + Dashboard kéo thả + Web App
= Secret Manager UI

Game thủ + Cấu hình máy + Auto-detect + Desktop App
= Game Optimizer

## 10 mô hình kinh doanh
- $5-10/tháng: Personal utility (một người dùng)
- $10-30/tháng: Team tool (2-10 người)
- $30-100/tháng: Business (10-100 người)
- $1-5/lần: One-time purchase (Desktop app, plugin)
- Free + donation: Open source + sponsorship
- Free tier + premium: Freemium
- API pricing: Pay per request
- White label: Bán cho agency rebrand
- Marketplace: App store cho niche
- Content + community: Free tool → bán course/ebook

## 5 bước chọn ý tưởng
1. Bạn có đang gặp vấn đề này không? (Nếu không → bỏ qua)
2. Có 1000 người khác cũng gặp không? (Nếu không → bỏ qua)
3. Họ có sẵn sàng trả tiền không? (Nếu không → bỏ qua)
4. Bạn có thể build MVP trong 2 tuần không? (Nếu không → simplify)
5. Có ai đã làm tử tế chưa? (Nếu rồi → tìm góc khác)
